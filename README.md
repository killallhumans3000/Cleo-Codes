# Cleo-Codes – Gästeliste App

Eine Gästelisten-App auf Basis von [Next.js](https://nextjs.org) und [Supabase](https://supabase.com).

## Projektstruktur

```
gaesteliste-app/   # Next.js App
```

## Setup

```bash
cd gaesteliste-app
npm install
npm run dev
```

Die App läuft dann unter [http://localhost:3000](http://localhost:3000).
